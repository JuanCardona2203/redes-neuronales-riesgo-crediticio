# Índice de Notebooks del Proyecto

Esta carpeta contiene la secuencia ordenada de notebooks para la preparación de datos, definición matemática, arquitectura y entrenamiento de la red neuronal.

| Notebook | Contenido y Propósito |
| :--- | :--- |
| `01_datos.ipynb` | Importación del dataset financiero y análisis exploratorio inicial (EDA). |
| `02_quality.ipynb` | Control de calidad: detección de outliers, imputación y normalización. |
| `03_fundamentos.ipynb` | Explicación matemática y paso a paso del cálculo lineal y función de activación. |
| `04_architecture.ipynb` | Declaración de la estructura Keras/PyTorch (Capa de entrada, ocultas y salida). |
| `05_forward.ipynb` | Verificación de compatibilidad de dimensiones de los tensores durante la inferencia. |
| `06_training.ipynb` | Entrenamiento del MLP con Binary Cross-Entropy y optimizador Adam. |
