# Módulo Source (src)

Este directorio contiene los componentes de código reutilizables del proyecto:
- `model.py`: Contiene la definición formal de la arquitectura de la Red Neuronal Densa (Perceptrón Multicapa - MLP) implementada en PyTorch.
- `predict.py`: Funciones de inferencia (`cargar_modelo`, `predecir`) y lista de variables de entrada, usadas por el notebook de despliegue y la aplicación.
